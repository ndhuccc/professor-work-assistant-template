# 郵件、期限、推薦資料與行政文件

## 輸入
使用者指定來源、日期範圍、人物與任務；需自己的授權信箱／行事曆等工具，或使用者提供的匯出文件。

## 程序
1. 讀 AGENTS.md、docs/QUALITY.md、docs/PRIVACY.md。確認帳號、搜尋範圍及當前工具。連線缺失時可處理已提供檔案，不能聲稱看過信箱。
2. 查詢後讀完整相關信件／附件／表單，不只依搜尋摘要。若工具有分頁則完成必要分頁並回報涵蓋範圍。
3. 從權威來源擷取正式截止日，保留原文日期／時區，轉換設定時區；矛盾或缺時區列待確認。先列即將到期與需要使用者決定的事項。
4. 推薦資料只採用使用者提供且可核實的經歷，不編造成績、研究成果、關係或評價。辨識附件與目標學校，保留個別版本。
5. Word／PDF／試算表／簡報使用當前環境可用工具，先完成草稿，轉換後檢查頁數、字型、表格、圖片與公式；缺渲染能力時明示目視未執行。
6. 寄信、送出表單、暫存到外部表單、建立／變更行事曆或分享文件都屬外部更動；先驗證收件者／目的地並列出內容及影響，取得具體確認後執行及讀回。
7. 排程只依明確來源、範圍、頻率、時區與動作設定；無排程能力就交付設定草稿，不承諾未建立的提醒。

## 輸出與驗收
私人期限／待辦表、附件與來源位置、文件草稿、已核實／推論／無法驗證清單。不得把草稿說成已寄出、已提交或已排程。
