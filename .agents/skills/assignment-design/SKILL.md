# 作業、評分標準與匯入檔設計

## 輸入
課程與本週教材、學習目標、學生程度、允許工具、個人／分組、配分與解答政策；正式期限只取教師核准來源。

## 程序
1. 讀 AGENTS.md、docs/QUALITY.md、docs/PRIVACY.md 及該課本次作業規範。只問尚缺且必須決定的條件，不沿用其他課程的日期。
2. 建立目標 → 題目 → 可觀察成果 → 評分項目的對應，控制預期工作量；題目提供足夠輸入、格式與驗證方法。
3. 指定繳交檔案、目錄、可重現指令、依賴、資料使用與 AI 使用揭露政策。設計能查核過程的證據，不只要求最後數字。
4. 撰寫 rubric：各項配分、通過／部分／未達條件與扣分界線；驗算總分，防止同一錯誤重複扣分。教師決定最後政策。
5. 公開題目與教師解答分開存放；解答必須在合格私人位置。不能靠網頁隱藏解答而將其寫入公開 Git 歷史。
6. 要求 LabTube 匯入時先取得目前課程代碼、schema、範例及驗證工具；依實際格式生成、解析檢查，再於核准後匯入。不把示範代碼當成已核准代碼。

## 輸出與驗收
題目 Markdown、rubric、教師解答（如授權）、繳交清單、匯入檔（符合已取得契約時）。
來源、分數與日期正確，公開與私人輸出分離。沒有正式期限就標示待確認，不自行設定或公告。
