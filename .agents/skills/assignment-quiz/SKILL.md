# 個人化三題作業理解測驗

## 輸入
教師指定作業、學生繳交版本、學習目標與題目／解答政策；私人目的地同 W08。

## 程序
1. 讀 AGENTS.md、docs/QUALITY.md、docs/PRIVACY.md，靜態閱讀指定 hwNN／tag／commit 的作業。不執行學生程式、不讀其他學生來補缺項。
2. 建立該學生實作的三個可查核理解點：設計選擇、程式機制、邊界／反事實行為。
3. 各設計一題簡答，共三題；引用學生實際函式、參數或結果，題意獨立清楚，不使用一般選擇題技能代替。
4. 分開建立學生題本及教師答案／評分依據；題目保留來源定位，答案包含必要概念、可接受變體與部分給分條件。
5. 施測後，依原題與 rubric 閱讀回答；列出回答證據、概念理解、錯誤與待追問項目，提供教師初評，不自動發布成績。

## 輸出與驗收
私人三題題本、獨立教師解答、來源對照；有回答時才產出初評。核對確實只有三題、每題能從指定實作理解並回答。
寄送題目、啟動測驗與回覆學生另需教師對具體對象及內容的核准。
