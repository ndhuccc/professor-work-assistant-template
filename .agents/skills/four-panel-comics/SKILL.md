# 逐核心概念加入四格漫畫

## 輸入
可讀取的原始簡報、目標格式、可用生圖與格式處理工具；不改動原檔，先建立工作副本。

## 程序
1. 讀 AGENTS.md、docs/QUALITY.md，解析所有頁面及順序，提取每個核心概念，建立概念 ID、來源頁 ID、學習目標、必要前提與漫畫插入錨點。
2. 同一概念合併重複頁；一頁含多個獨立概念則分列。每個概念各一張漫畫，不把全份簡報只畫成一張。跨多頁概念錨定完整解釋後的頁面。
3. 為每概念規劃 16:9 橫式、2×2 四格：左上提出問題、右上展示嘗試、左下解釋關鍵機制、右下展示結果與限制。角色可愛、內容簡單易讀，因果與數學必須正確。
4. 畫面短句使用指定語言，避免密集小字。生成提示詞含概念、四格情節、必要符號、構圖、風格與不可出現的誤解。使用生圖工具；未提供時交付分鏡與提示詞並標示圖片未生成。不可用程式繪圖假稱生圖成果。
5. 檢視生成圖像；文字錯誤、順序混亂或概念失真時修訂。精密公式／數值另用可控文字或向量層顯示，避免生成錯字。
6. 支援 JPEG 壓縮嵌入：保留原始生成檔，另建立 JPEG 交付副本，透明圖需經使用者同意或既定白底規格後合成底色。品質可先從 88–92、寬度 1920px 試算，依文字可讀性調整；不是硬性通過門檻。不要只改副檔名；MIME、檔案實際格式與 data URI 必須一致。圖像編輯依目前環境規則使用適合工具。
7. 將漫畫新增為獨立頁並插在對應內容之後，絕不疊在原內容上。PPTX／HTML 以頁序插入；簡報島等空間畫布須先核對 schema、頁寬與 gutter，重排所有後續頁的座標及索引，驗證每個頁面包圍盒不相交。保留原頁 ID、連結與使用者修改。
8. 再次讀取輸出，驗證所有圖片可解碼、嵌入格式正確、每概念一張、順序正確、頁數符合預期、沒有任何頁面重疊／裁切；比較壓縮前後大小及實際全螢幕可讀性。

## 輸出與驗收
新檔 `<stem>-with-comics.<ext>`、概念／來源頁／插入頁清單、圖檔或嵌入清單、大小比較、驗證報告。
未取得專用格式契約時不能假稱已完成嵌入；可先交付圖片與插頁計畫。原簡報與原圖保留。
