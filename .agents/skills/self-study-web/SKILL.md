# 自學指南與閱讀網頁

## 輸入
已製作的講義／投影片及來源對照，指定自學指南、閱讀網頁或兩者。

## 程序
1. 讀 AGENTS.md、docs/QUALITY.md。盤點原頁的概念、例子、公式與銜接；不能只依頁面標題擴寫。
2. 自學指南以因果鏈串接：為何需要本觀念 → 前提 → 機制 → 實例 → 限制 → 下一個觀念。
3. 每段在關鍵處加入「停一下想想」、簡短可驗證的小練習與明確解釋，避免先拋未定義術語。教學用解答依使用者政策，未公開試題不嵌入公開頁面。
4. 閱讀網頁以 Markdown 為來源主檔，保留標題、表格、清單、連結、圖片及 LaTeX。HTML 語意化，提供目錄、閱讀進度或合適導覽；不把全文轉成圖片。
5. 排版適合手機與桌面，公式及表格允許橫向捲動但不推擠全文；使用指定樣式，無指定時採易讀的留白與高對比。
6. 檢查標題 anchor、內部連結、公式初始化、特殊字元與原文覆蓋；逐尺寸驗證，記錄外部資源與離線限制。

## 輸出與驗收
自學指南 Markdown／HTML、閱讀頁及需要的資源、來源對照與驗證報告。不得靜默取代或覆寫來源 Markdown。
