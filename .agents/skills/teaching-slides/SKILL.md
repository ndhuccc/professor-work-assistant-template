# 講義轉教學投影片

## 輸入
已核對講義、學習者程度、KP 清單、格式；原始投影片更新時保留使用者修改。

## 程序
1. 讀 AGENTS.md、docs/QUALITY.md 與對應講義；建立核心概念到頁次的對照。每頁只承載一個主要教學問題，不能把講義整段縮小塞入。
2. 依「問題 → 直覺 → 定義 → 推導 → 例子 → 總結／檢查」規劃；每個 KP 獨立一個檔案，保留必要跨頁推導。
3. 未指定格式時使用 16:9 HTML 投影片與可辨識的上一頁／下一頁及鍵盤操作，預設 HTML5／CSS／原生 JS。無需安裝前端框架。按容器等比縮放或採不截切的適應版面。
4. 數學使用可用 KaTeX／MathJax，處理載入、重複渲染及公式大小；標示外部依賴。無法載入引擎須明示，不能把裸公式說成完成。
5. 指定簡報島 .jbd.json 時，先讀取使用者提供的可用樣本、目前 schema 與播放器契約，建立格式與座標對照。未具備契約時先交付頁面內容及 HTML 預覽，不自行編造可匯入 JSON，也不可將 PPTX 改副檔名替代。
6. 指定 PPTX 時使用環境可用的簡報工具；檢查實際投影片順序、邊界、字型與渲染結果。
7. 依品質規範逐頁檢查文字、公式、圖例與按鈕，記錄實測尺寸與未執行項目。

## 輸出與驗收
每 KP 投影片、頁面規劃／來源對照、驗證報告；有圖檔附可攜相對路徑或正確嵌入。
重新開啟與操作後才標記播放驗證通過。需要漫畫時接 W04，插入後再驗證。
