# 能力與降級方式

| 工作 | 最低需求 | 缺少工具時可完成的部分 |
|---|---|---|
| 來源盤點、Markdown 講義、紀錄 | 能讀寫本機文字檔的 Agent | 無檔案寫入時在對話提供草稿，明示尚未儲存 |
| PDF／DOCX／PPTX | 能讀取該格式的工具及必要渲染器 | 整理使用者提供的可讀摘錄，列出未覆蓋範圍 |
| HTML 投影片／閱讀頁 | 文字檔寫入；目視驗證需瀏覽器 | 產出 HTML 並做靜態檢查，目視列未執行 |
| 簡報島／LabTube 匯入 | 目前版本的 schema、可用範例及驗證器／播放器 | 產出中立內容規劃，不假裝已生成可匯入檔 |
| 四格漫畫圖像 | 生圖工具；嵌入另需圖片與簡報處理工具 | 交付核心概念表、分鏡、提示詞及插頁計畫 |
| GitHub 狀態／提交／部署 | 自己的 connector 或 git／CLI 與帳號權限 | 分析本機副本，明示遠端狀態未核實 |
| 信箱／行事曆／Drive／Notion | 自己的授權連線及可用操作 | 處理匯出的檔案、撰寫待確認草稿 |
| 作業與研究初評 | 指定來源、版本與合格私人輸出位置 | 先盤點來源與評閱規格，不外傳敏感結果 |

範本不會替 Agent 安裝外部服務、不內含憑證，也不會自動定期執行。
排程須由使用者明確指定來源、範圍、頻率、時區與動作，再使用當前環境的排程功能；沒有該能力時如實回報。
`doctor.py` 的 PASS 是本機結構驗證；外部能力標記仍需實測。不要以 CLI 已安裝推論帳號已登入或可推送。
