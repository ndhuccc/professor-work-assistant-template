# 隱私與資料邊界

範本只包含通用規範與虛構示例；不要加入真實學生名冊、學號、成績、評語、論文私密資料、推薦內容、信件或憑證。
下載範本不會取得原作者帳號或權限。公開與私人倉庫均需遵守相同資料最小化原則。

學生初評、個人化測驗、研究審查與推薦資料的輸出目的地：

1. 由使用者明確指定私人目錄或服務；不得自行猜測主機或共用對象。
2. 本機目錄必須在本範本及所有已知課程／學生 Git 工作樹以外；檢查 git 根目錄及父層，不只檢查 .gitignore。
3. 未滿足條件時先完成無敏感資料的來源盤點與輸出規格，再詢問必要目的地。
4. 不寫入學生 Repo，不將教師評閱初稿當成最後成績，不自行認定抄襲或遲交。

本機設定、workspace、秘密、憑證、輸入輸出與私人報告預設不追蹤。公開教材需經審閱，明確移入要發布的路徑後，使用明確檔案清單提交。
避免 `git add .`；先檢查 staged diff、已追蹤路徑及歷史風險。gitignore 不會移除已追蹤的秘密。
若發現洩露，停止發布並向使用者回報可確認的範圍；撤銷憑證與歷史重寫等動作另外取得具體授權。
任務紀錄以必要中繼資料和來源位置為主；敏感檔名或 URL 本身可能洩露資料，應保存在同等私人位置。
