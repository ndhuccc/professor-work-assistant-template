## Agent 實際載入與檢查

config/workflows.json 每個正式程序都有 workflow_path。AGENTS 啟動步驟要求先執行 reader，按 workflow → 原主技能 → 必要參考的順序讀取；無 Python 時完整人工讀檔。
scripts/read_workflow.py 接受 ID、技能名或六個相容別名，預設及 --json 都包含兩份完整文件內容；它只讀本機檔案，不執行業務或外部動作。
doctor 同時檢查路徑、文件存在與安全邊界、程序 ID、原主技能連結、總索引與未索引文件；原技能／來源／設定與 Markdown 連結檢查持續保留。
