# 研究生週報、論文與跨週事項審查

主要程序：W10。先遵循 [AGENTS.md](../AGENTS.md)、[來源與品質契約](../docs/QUALITY.md) 及 [隱私契約](../docs/PRIVACY.md)。

## 觸發與範圍

「審查本週研究進度」「對照教授上次意見查核論文」「比較這週 PR／直接提交的實驗證據」。
本流程提供教授端證據查核與審查草稿；學生自己撰寫週報、一般程式碼審查或正式研究合格判定，需另辨認任務及適用規準。
既有待辦的執行與查詢分開；不能因紀錄上寫了任務就自行執行。

## 必要輸入

- 使用者核准的名冊與學生／Repo 對應、研究計畫與規準、週次／Asia/Taipei 或指定時區。
- 本週與上週週報、教授前次決定、所有未結案事項、論文／實驗結果／資料切分與設定。
- 指定 Repo、分支、比較起訖版本或已約定日期界線；需要的私人輸出位置。
- config/project.local.json 的 research 私人來源可先重用；沒有就列缺項，不從帳號擁有者推定學生身分，也不使用範本原作者的名冊。

## 技能與工具

主要使用 [review-graduate-research](../.agents/skills/review-graduate-research/SKILL.md)；讀取它指定的 source-guide、續篇、名冊設定與 review-template。
跨週狀態及交接使用 [mission-log](../.agents/skills/mission-log/SKILL.md)，必要時依 [W12 程序](repo-maintenance.md)；發布草稿另走 W13。
工具為目前使用者自己的 GitHub／文件／雲端來源讀取能力。此範本沒有自動審查腳本、私人名冊或預先授權的 Notion 目的地；歷史 references 的可攜重建範圍以技能聲明為準。

## 執行程序

1. 核對人、來源、版本、規準及週次，將每個來源標為已讀、不可讀、缺漏或矛盾。所有範圍內學生都需列結果；權限不足不等於未繳交。
2. 建立證據索引：學生代號、來源標題／精確位置、日期、頁碼／段落／圖表、分支與 commit。搜尋命中後讀原文；學生自述完成只證明其聲明。
3. 先接續教授核准的歷史事項，保留原編號、首次提出日期、負責人、完成條件、原期限與教授決定來源。早於上週但尚未結案的事項也要帶入，不因本週沒提到而刪除。
4. 逐項比對「聲稱 → 實際證據 → 核准完成條件 → 可支持的判斷 → 缺口」。核對研究問題、方法、樣本與切分、參數、基準、單位、指標算法及重複次數；區分觀察、推論與未知。
5. GitHub 有 PR 就讀 diff、討論及測試紀錄；沒有 PR 就讀指定分支的直接 commits。優先由前次保存 SHA 比較至本次 SHA，關聯重複證據，不能以 PR 數、commit 數或更新時間替代研究品質。
6. 區分「已執行且有紀錄」「紀錄顯示未執行」「本次未見測試證據」「Agent 本次未執行」。預設不跑學生程式或實驗；若需重現，先列資料、環境、命令、時間／費用與授權，作獨立動作處理。
7. 對每個問題用「發現什麼 → 為何重要 → 接下來做什麼 → 如何確認完成」寫白話草稿。主文面向不懂 Git、深度學習背景有限的大學生；必要術語就地解釋，技術版本與證據集中於對應附錄。
8. 產出全班／研究室摘要、逐生審查、跨週表與具體補件問題。沒有核准期限寫未設定；完成證據充分但尚無教授確認，標「已提出完成證據，待教授確認」。新建議與既有教授要求分開。
9. 依約定私人位置存檔，透過 W12 保留來源、狀態建議及未決事項。通知學生、Issue、留言或修改正式追蹤狀態均另核對具體授權，不能把存檔當成已發送。

## 確認節點

缺少／衝突的身分、規準、版本或前次紀錄，暫停受影響判定並集中問最關鍵缺項，其餘唯讀整理可繼續。
教授做最後研究判斷、期限變更、取消及結案決定。核准審查不自動包含寄送、分享、推送、合併或排程；已具體核准的同一動作則沿用。
遵守各自資料夾範圍，不擅自改學生研究檔、建立權限系統或放寬存取。

## 輸出與驗收

輸出本週重點與最大風險摘要、逐生證據對照、完整跨週事項表、補件問題、私人報告與 W12 位置紀錄。
每項重要判斷可追溯到實際來源與版本；所有核准學生均被涵蓋；舊編號／決定／期限保留；事實、推論與未知分開。
逐段檢查主文、表格、圖說與附錄的可讀性，數值、單位、限制及未知不因白話改寫而遺失。
草稿、已存檔、已核准、已發送及已更新外部紀錄各有獨立證據；未讀回不回報已驗收。

## 失敗處理與交接

找不到前次決定就標跨週追蹤待確認，附已查範圍與可補來源；不可假定以前沒有要求。論文新舊版混用時先建立版本對照，再恢復逐項查核。
來源不可讀保留阻礙與下一步；不得換用他人帳號。外部操作結果不明先查現況，不重複送出。
交接包含週次、學生範圍、規準、起訖 SHA、已讀來源、舊待辦、輸出實際位置及需要教授決定的事項；保留他人原紀錄與事件歷史。
